# 🧠 Neural Networks From Scratch

A hands-on implementation of fundamental Deep Learning architectures **from scratch**, focusing on understanding the mathematics, forward propagation, backpropagation, and training process rather than relying entirely on high-level deep learning APIs.

The goal of this repository is to understand **what happens inside neural networks** by implementing their core operations manually.

---

## 🚀 Architectures

This repository currently covers:

- ✅ Artificial Neural Network (ANN)
- ✅ Recurrent Neural Network (RNN)
